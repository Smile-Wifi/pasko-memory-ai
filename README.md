# Christmas Photo Magic — Page 02: Photo Creator

Open `create.html` directly in a browser or use Live Server.

Features: portrait upload and preview (10 MB limit), Basic ₱99 and Premium ₱149 selection, six template style choices, customer name/email/phone, consent checkbox, summary, and a demo order draft stored in browser localStorage.

This is a frontend prototype only. It is NOT connected to Supabase, payments, or AI generation. Replace the demo localStorage flow with secure server-side order creation and private storage before production. Do not store customer images in localStorage for production use.
